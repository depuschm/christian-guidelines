# Sources

Every source linked from the guidelines, grouped by score. The criteria are in [RANKING.md](RANKING.md).
*Verified* is the date someone last checked that the page still says what the guidelines cite it for.

This file is generated from [sources.csv](sources.csv) by `python3 scripts/rank.py fix`. Change scores in the CSV, not here.

Bible passages aren't listed: the guidelines link 159 passages, each to the same public domain edition,
the [World English Bible British Edition with Deuterocanon](https://ebible.org/eng-webbe/) ([ADR-0009](docs/decisions/0009-quote-and-link-one-public-domain-translation.md)).
Each counts as a source with score 7, and `python3 scripts/bible_refs.py check` checks that every reference links to the right chapter and verse.
